# LectureNote 발표 디자인 가이드

경영전략 9팀 | 이병헌 · 김도환 · 최철원  
*1~3차 발표 PPT/PDF 실물 기반으로 작성*

## 1. 컬러 시스템

실제 슬라이드에서 추출한 색상. 차수별로 진화했지만 동일한 팔레트를 공유한다.

| 역할 | 이름 | 근사 HEX | 사용처 |
|------|------|----------|--------|
| 배경 메인 | Deep Navy | `#1A2D5E` | 표지·섹션 슬라이드 전체 배경, 카드 헤더, 풋터 |
| 강조 1 | Sky Blue | `#4B82C5` | 세로 구분선, INPUT 박스, 하단 풋터 바, 현재 단계 원 |
| 강조 2 | Green | `#22C55E` | 완료 상태, 체크 아이콘, SDLC 100% 바, Step 0 출력 박스 |
| 강조 3 | Orange / Amber | `#F59E0B` | 현재 위치(★), 진행 중 SDLC 바, 3차 발표 현재 마일스톤, GET 배지 |
| 강조 4 | Terracotta | `#C17C5B` | LLM 비교표 Claude 컬럼, STT BEFORE 상태 표시 |
| 배경 보조 | White | `#FFFFFF` | 내용 슬라이드 배경 |
| 표면 | Light Gray | `#F0F2F7` | 카드 배경(흰 슬라이드 위), 미착수 SDLC 바 |
| 본문 | Charcoal | `#1C1C1E` | 흰 배경 위 본문 |
| 보조 텍스트 | Gray | `#6E6E73` | 카드 소제목, 캡션 |
| 경고 | Red Square | `#E74C3C` | 1차 기존 서비스 단점 불릿 아이콘 |

**배경 선택 원칙**

| 슬라이드 유형 | 배경 | 텍스트 |
|--------------|------|--------|
| 표지 | Deep Navy 전체 | 흰색 |
| 목차 (3차 스타일) | Deep Navy 전체 | 흰색 |
| 아키텍처·파이프라인 | Deep Navy 전체 | 흰색 |
| 비교 표 (STT, LLM) | 흰색 | Charcoal |
| 원가 분석·데모 | 흰색 | Charcoal |
| 로드맵 | Deep Navy 전체 | 흰색 |
| 마무리·결론 | Deep Navy 전체 | 흰색 |
| 일반 내용 | 흰색 또는 Navy 혼합 가능 | 상황에 따라 |

## 2. 타이포그래피

| 용도 | 굵기 | 크기 |
|------|------|------|
| 표지 영문 서비스명 (LectureNote) | ExtraBold 또는 이탤릭 | 80–100pt |
| 표지 한국어 서비스명 | Bold | 36–40pt |
| 슬라이드 제목 | Bold | 32–40pt |
| 슬라이드 부제 (우측 상단 작게) | Regular | 16–18pt |
| 카드 제목 | Bold | 20–24pt |
| 카드 본문 | Regular | 14–16pt |
| 풋터 바 텍스트 | Regular | 14pt |
| 기술 스택 태그 | Regular | 12–14pt |

- 한국어 폰트: **Pretendard** 우선, 없으면 맑은 고딕 / Apple SD Gothic Neo
- 영문 폰트: Pretendard 또는 시스템 Sans-serif
- 이탤릭 사용: 표지 영문 서비스명, 슬태그라인에 한정

## 3. 슬라이드 구조 패턴

### 3-1. 표지 (1차 스타일)

```
┌──────────────────────────────────────────────┐
│               [Deep Navy 전체 배경]            │
│                                               │
│         LectureNote   ← 대형 이탤릭 흰색      │
│           렉쳐노트    ← Bold 흰색              │
│                                               │
│   "녹음, 자료, 필기 — 모두 하나의 노트로"      │
│              ← 이탤릭 회색 슬태그라인          │
│                                               │
├───────────────────────────────────────────────┤
│  [Sky Blue 풋터 바]  경영전략 팀 프로젝트 | 9팀 N차 발표  │
└───────────────────────────────────────────────┘
```

### 3-2. 표지 (2·3차 스타일)

```
┌──────────────────────────────────────────────┐
│  [Deep Navy 전체 배경]  차수 정보 소형 (좌상단)│
│ ┃ (Sky Blue 좌측 세로선 4–6px)               │
│                                               │
│ LectureNote    ← Bold 흰색 대형               │
│ 렉쳐노트       ← Bold Sky Blue                │
│ ─────────────  ← Sky Blue 구분선             │
│ 발표 부제      ← Regular 흰색                 │
│ 세부 설명      ← Light 회색                   │
│                                               │
├───────────────────────────────────────────────┤
│  [팀장/팀원 정보]  |  연도                     │
└───────────────────────────────────────────────┘
```

3차에서는 우측 상·하단에 반투명 원형 장식 추가됨.

### 3-3. 목차 슬라이드 (3차 스타일)

```
[Deep Navy 배경]  제목: 발표 구성

┌──────────────┐  ┌──────────────┐
│ ① Sky Blue원 │  │ ② Sky Blue원 │
│  섹션 제목   │  │  섹션 제목   │
│  부제 Gray   │  │  부제 Gray   │
└──────────────┘  └──────────────┘
┌──────────────┐  ┌──────────────┐
│ ③           │  │ ④           │
└──────────────┘  └──────────────┘
┌──────────────┐  ┌──────────────┐
│ ⑤           │  │ ⑥           │
└──────────────┘  └──────────────┘
┌──────────────┐  ┌──────────────┐
│ ⑦           │  │ ⑧           │
└──────────────┘  └──────────────┘
```

번호 원: Sky Blue 채움, 흰색 숫자.  
카드: Navy보다 약간 밝은 Blue-Gray 배경, 테두리 없음.

### 3-4. 3열 카드 슬라이드 (1차 문제 정의 등)

```
[흰색 배경]  제목 (Navy Bold 좌상단)

┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│  [Navy 헤더] │ │  [Navy 헤더] │ │  [Navy 헤더] │
│     01       │ │     02       │ │     03       │
├──────────────┤ ├──────────────┤ ├──────────────┤
│              │ │              │ │              │
│  카드 제목   │ │  카드 제목   │ │  카드 제목   │
│  ─────────   │ │  ─────────   │ │  ─────────   │
│              │ │              │ │              │
│  설명 Gray   │ │  설명 Gray   │ │  설명 Gray   │
│              │ │              │ │              │
└──────────────┘ └──────────────┘ └──────────────┘
```

카드 헤더 숫자: 흰색 대형, 카드 제목 아래 Sky Blue 짧은 밑줄 강조선.

## 4. 반복 컴포넌트 실제 스펙

### 4-1. SDLC 프로그레스 바

실제 색상 (3차 발표 기준):

```
요구분석  [████████████████████████] 100%  ✓ 완료 (N주차)  ← Green 바
시스템설계 [████████████████████████] 100%  ✓ 완료          ← Green 바
구   현   [██████████░░░░░░░░░░░░░░]  35%  ◀ 현재           ← Orange 바
테스트    [░░░░░░░░░░░░░░░░░░░░░░░░]   0%    예정           ← 어두운 Navy 바
배   포   [░░░░░░░░░░░░░░░░░░░░░░░░]   0%    예정           ← 어두운 Navy 바
```

- 라벨 텍스트: 흰색 (Navy 배경 위) 또는 Charcoal (흰 배경 위)
- % 숫자: Green(완료), Orange(진행), 회색(미착수) 각각 강조색으로 표시

하단에 세부 근거 표 추가:

| 구현 영역 | 상태 |
|----------|------|
| 백엔드 API 서버 | ✅ 완료 (Green 배경) |
| … | ⬜ 미착수 (회색 배경) |

### 4-2. 로드맵 타임라인

실제 패턴 (3차 기준):

```
상단 라벨 행:
[1차발표 Sky Blue 박스] [2차발표 Sky Blue 박스] [3차발표★ Orange 박스]

주차 텍스트:
1-2주차    3주차    4주차    6주차    8주차   10주차   13주차

타임라인:
●────────●────────●────────◉────────○────────○────────○
(Green 채움)       (Green)  (Orange 현재)  (빈 원, 회색)

하단 레이블:
아이디어  요구분석  시스템설계  백엔드MVP  알파빌드  베타테스트  최종발표
기획      완료      완료        완료        완성      피드백     런칭로드맵
```

- 완료 마일스톤 원: Green 채움 ●
- 현재 위치 원: Orange 채움 ◉ + 상단 Orange 라벨 박스
- 미래 원: 빈 원 ○, 회색 테두리
- 연결선: 완료 구간 Green, 미래 구간 점선 회색

### 4-3. 시스템 아키텍처 다이어그램

**2차 발표 (흰 배경 위 Navy 색조 박스):**

```
INPUT              PROCESSING           OUTPUT
┌──────────────┐   ┌────────────────┐   ┌──────────────────┐
│ 🎤 음성 녹음 │   │ Data Aggregator│   │ 과목별 구조화 노트│
│ Sky Blue 배경│ → │ Navy 배경      │ → │ 시험 예상 문제    │
├──────────────┤   └───────┬────────┘   │ PDF 저장          │
│ 📄 수업 PDF  │           ↓            └──────────────────┘
├──────────────┤   ┌────────────────┐
│ ✏️ 필기 노트 │   │ Gemini 1.5 API │
│ 흰 배경+점선 │   │ Sky Blue 배경  │
└──────────────┘   └────────────────┘
```

**3차 발표 (Navy 전체 배경 위 2단계 박스):**

```
[좌 패널 - 강의 등록]     [우 패널 - 노트 생성]
Sky Blue 테두리 박스       Navy 박스 (더 밝은)
- 사용자 → 강의계획서 PDF  - 강의 녹음, 수업 PDF, 필기
- Gemini LLM 분석          - Data Aggregator
- Step 0 로드맵            - Gemini LLM
- [Green] DB 저장          - [Green] DB저장 / HTML다운로드
```

연결 화살표: Orange (두 패널 사이 큰 화살표)

### 4-4. 비교 표 (LLM/STT 비교)

**LLM 비교표 (1차):**
- 헤더 행: Navy / Terracotta(Claude) / Green(GPT) / Sky Blue(Gemini) - 각 컬럼 색 다름
- 데이터 행: 흰-연회색 교대, 텍스트 Charcoal
- 우위 셀: 해당 컬럼 색상으로 Bold 강조

**STT 비교표 (2차):**
- 헤더 행: Navy 배경 흰색 텍스트
- 선택된 행 (현재 전략): Sky Blue 왼쪽 강조 테두리 or 배경
- 비용 수치: 낮을수록 Mint/Green, 높을수록 Orange/Red

**Before/After 비교표 (3차 STT 변경):**
- BEFORE 헤더: Terracotta/갈색 배경
- AFTER 헤더: Green 배경
- 행 데이터: 흰 배경, 변경된 셀만 Green Bold

### 4-5. 원가 구성 시각화 (2차)

```
[흰 배경]  좌: 항목별 표  |  우: 수평 바 차트
                           ████████████████████  Red(STT 90%)
                           ██  Green(LLM)
                           █   Blue(인프라)
                           █   Gray(기타)
```

하단: Red 경고 박스 (⚠️ 아이콘 + "역마진 구조" Bold Red)

### 4-6. 3열 번호 카드 (2차 마무리, 3차 STT변경 이유)

```
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│   ① [원 아이콘] │ │   ② [원 아이콘] │ │   ③ [원 아이콘] │
│   카드 제목     │ │   카드 제목     │ │   카드 제목     │
│   ─────────     │ │   ─────────     │ │   ─────────     │
│   본문 Gray     │ │   본문 Gray     │ │   본문 Gray     │
└─────────────────┘ └─────────────────┘ └─────────────────┘
```

번호 원: Sky Blue 채움(2차), Orange 채움(3차)  
카드 배경: Navy 배경 위 약간 밝은 Navy (테두리로 구분)

### 4-7. API 메서드 배지 (3차 백엔드)

```
[POST 녹색 배지]  /api/create-step0   강의계획서 분석
[POST 청색 배지]  /api/generate-note  통합 노트 생성
[GET  주황 배지]  /api/download-note  노트 다운로드
```

배지: `POST` = Green, `GET` = Orange (Amber), 배경 배지 형태  
카드 테두리: 배지 색과 동일 계열로 테두리

### 4-8. 기술 스택 태그

```
[Python 3.13]  [FastAPI]  [SQLite + SQLAlchemy]  [PyMuPDF]  [google-genai SDK]  [python-dotenv]
```

각 태그: 둥근 테두리(border-radius 20px), Navy 배경, 흰 텍스트  
가로 나열

### 4-9. 노트 결과물 5섹션 표시 (3차)

```
좌측: 실제 HTML 노트 캡처 이미지 (흰 배경)

우측: 5개 세로 카드
┌─────────────────┐ ← Sky Blue 배경: Overview
├─────────────────┤ ← Navy 배경: 통합 노트

└─────────────────┘ ← 연Navy 배경: 셀프 시험
```

각 섹션 제목 Bold 흰색, 설명 Light 흰색

### 4-10. Before / After 비교 카드 (3차 차별화)

| 차수 | 슬라이드 수 | 배경 경향 | 주요 변화 |
|------|------------|----------|-----------|

## 6. 슬라이드 풋터 바 규칙

- **Sky Blue 배경 풋터 바**: 표지 하단 ("경영전략 팀 프로젝트 | 9팀 N차 발표")
- **Navy 배경 풋터 바**: Navy 배경 슬라이드 하단 요약 문구 ("핵심 한 줄 요약")
- **풋터 없음**: 흰 배경 내용 슬라이드 (텍스트만으로 구성)
- 풋터 높이: 슬라이드 높이의 약 7–8%
