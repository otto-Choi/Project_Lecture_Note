# LectureNote 발표 디자인 시스템
> 1차~5차 발표자료 분석 기반 — 6차 PPT 제작 시 참고

## 2. 타이포그래피

| 용도 | 스타일 | 크기(참고) |
|---|---|---|
| 표지 로고 (LectureNote) | Bold, 흰색 + 액센트 블루 ('Note') | 60~80pt |
| 슬라이드 메인 제목 | Bold, 흰색 | 36~44pt |
| 섹션 라벨 (`01 · 섹션명`) | Regular, 연회색 | 12~14pt |
| 부제·설명 라인 | Regular, 연회색 | 16~18pt |
| 카드 제목 | Bold, 흰색 | 20~24pt |
| 카드 본문 | Regular, 연회색·흰색 | 14~16pt |
| 표 헤더 | Bold, 흰색 | 14~16pt |
| 표 본문 | Regular, 흰색·연회색 | 13~15pt |
| 코드·URL | Monospace (Consolas 등), 라이트 블루 | 13~14pt |
| 푸터 텍스트 | Regular, 연회색 | 11~12pt |

## 4. 컴포넌트 패턴

### 4-1. 기능 카드 (4열·3열 그리드)

5차 "베타 빌드 신규 기능" 슬라이드 패턴:

```
┌───────────────────┐  ┌───────────────────┐
│ 01          [NEW] │  │ 02          [NEW] │  ← 뱃지: 파랑NEW / 초록LIVE
│                   │  │                   │
│ 카드 제목          │  │ 카드 제목          │
│ Bold, 흰색         │  │ Bold, 흰색         │
│                   │  │                   │
│ 설명 텍스트        │  │ 설명 텍스트        │
│ 회색, 소형         │  │ 회색, 소형         │
│ ─────────────────│  │ ─────────────────│
│ KEY               │  │ SCREENS           │  ← 컬러 레이블 (파랑)
│ 태그 텍스트        │  │ 태그 텍스트        │
└───────────────────┘  └───────────────────┘
```

- 카드 상단에 얇은 색상 바 (파랑/초록/오렌지/노랑)로 카테고리 구분 (4차 스타일)
- 5차는 카드 상단 바 없이 뱃지로 대체
- 모서리: 약간 둥글게 (8~12px radius)

### 4-2. 목차 카드 (5차 스타일)

```
┌─────────────────────────────────────────┐
│ 01                                      │
│ SDLC 진행 현황                           │  ← Bold 제목
│ 4차 대비 구현 단계 진척도                 │  ← 회색 설명
└─────────────────────────────────────────┘
```
- 목차 슬라이드: 3열 2행 그리드, 카드 클릭 영역처럼 표시
- 현재 강조 항목(데모 등): 카드 너비 넓게, 내부에 서브태그 추가

### 4-3. 타임라인 (4차·5차 공통)

```
  1차발표    2차발표    3차발표    4차발표    5차발표    6차발표
────●──────────●──────────●──────────●──────────●──────────★────
  1-2주차    3주차      5주차      8주차      10주차    13주차
  [파란 채움]                                        [오렌지★ 채움]

  완료점 = 파란 채움 원
  현재점 = 오렌지/노랑 채움 원 + ★ 텍스트
  미래점 = 빈 원 (테두리만)
```

하단에 별도 박스로 "이번 마일스톤 달성 항목" 체크리스트 배치:
- ✓ (초록) 달성 항목
- 미달성은 포함하지 않음

### 4-4. 표 (피드백·기술스택 등)

```
┌──────────┬──────────┬──────────────────────────┬──────────┐
│ 구분      │ 응답자   │ 피드백 요약               │ 반영 상태 │  ← 헤더: 다크 네이비
├──────────┼──────────┼──────────────────────────┼──────────┤
│ UX 강점  │ ...      │ ...                       │ ✓ 완료   │  ← 바디: 미드 네이비
│ 개선 요청│ ...      │ ...                       │ ⟳ 진행 중│
└──────────┴──────────┴──────────────────────────┴──────────┘
```

- 헤더: `#1B2A5E` 배경, 흰색 Bold 텍스트
- 바디 홀수행: `#243B6E`, 짝수행: 약간 더 밝게 또는 동일
- 카테고리 구분: 왼쪽 컬럼에 색상 뱃지 (UX강점=파랑, 기능강점=초록, 개선요청=주황)

### 4-5. SDLC 진행 바 (4차 스타일)

```
요구분석  ████████████████████  100%  ✓ 완료 (3주차)   ← 초록 바
시스템설계 ████████████████████ 100%  ✓ 완료 (4주차)   ← 초록 바
구  현    ████████████████████  100%  ✓ 완료 (10주차)  ← 초록 바
테스트    ████████████░░░░░░░░  80%   ◀ 현재 진행 중   ← 주황 바
배  포    ████████████░░░░░░░░  80%   ◀ 현재 온라인    ← 주황 바
```

6차에서는 SDLC 슬라이드 없으므로 참고만.

### 4-6. 상태 뱃지

| 뱃지 | 색상 | 사용 상황 |
|---|---|---|
| `NEW` | 파랑 배경 흰색 텍스트 | 신규 기능 |
| `LIVE` | 파랑(밝음) 배경 흰색 텍스트 | 배포 완료 기능 |
| `FINAL` | 주황 배경 흰색 텍스트 | 최종 단계 |
| `★` | 텍스트로만 | 현재 위치 강조 |
| `✓` | 초록 | 완료 항목 |
| `🔄` | 주황 | 진행 중 |

### 4-7. 하이라이트 박스 (중요 메시지)

5차 "REMAINING" 박스, "설계 메모" 박스 패턴:

```
┌─ [카테고리 라벨 — 소형 볼드 파랑] ──────────────────────┐
│                                                        │
│  본문 텍스트 — 보통 1~3줄. 강조 단어는 Bold 처리.       │
│  Bold 강조 텍스트는 흰색, 일반은 연회색.                 │
│                                                        │
└────────────────────────────────────────────────────────┘
```
- 배경: `#2E5DB3` (라이트 블루) 또는 `#1B3A6B` (약간 더 어두운 블루)
- 테두리: 없음 또는 왼쪽 파란 바

## 5. 모바일 폰 목업 (4차·5차 데모 슬라이드)

- iPhone 스타일 프레임 사용 (검은 테두리, 노치/다이나믹아일랜드 있음)
- 상단 상태바: 시간·배터리·신호 아이콘 포함
- 앱 화면: 실제 캡처 삽입
- 1슬라이드에 3~4개 폰 나란히 배치
- 각 폰 아래에:
  - `① 단계명` 소형 회색
  - **설명 Bold** 흰색
  - 서브설명 회색 소형
- 슬라이드 우측에 별도 정보 카드 배치 가능

```
[폰 목업]  [폰 목업]  [폰 목업]    ┌─────────────────┐
    ①          ②          ③       │ 핵심 정보 카드   │
  단계명      단계명      단계명    │ ...             │
  Bold 설명   Bold 설명   Bold 설명 └─────────────────┘
  회색 서브   회색 서브   회색 서브
```

## 6. 슬라이드별 패턴 (1차~5차 실제 사용)

| 슬라이드 유형 | 주요 패턴 | 참고 발표 |
|---|---|---|
| 표지 | 세로 파랑 바 + 대형 로고 + 팀명 + 푸터 | 4차·5차 |
| 목차 | 3×2 카드 그리드, 번호+제목+설명 | 4차·5차 |
| SDLC 현황 | 진행 바 + 세부 완료 항목 표 | 3차·4차·5차 |
| 로드맵 | 수평 타임라인 + 달성 체크리스트 | 4차·5차 |
| 기능 소개 | 3열 기능 카드 (번호+제목+설명+태그) | 4차·5차 |
| 데모 (폰 화면) | 3~4 폰 목업 + 우측 정보 카드 | 4차·5차 |
| 피드백 표 | 카테고리 뱃지 + 4열 표 + 하단 노트 | 5차 |
| 기술 스택 | 2열 표 (계층·기술·역할·상태) + 숫자 강조 카드 | 4차·5차 |
| 마무리 | 왼쪽 텍스트 + 오른쪽 카드 2개 (URL·팀원) | 5차 |

## 7. 푸터 바 (전 슬라이드 공통)

```
══════════════════════════════════════════════════════════
경영전략 팀 프로젝트   │   9팀 6차 발표   │   2026.06    N / 9
```

- 높이: 약 32~36px
- 배경: `#2A4A8E` (푸터 블루)
- 텍스트: 연회색, 12pt
- 좌측: 팀·발표 정보
- 우측: 페이지 번호 (`N / 전체`) — 표지·목차 제외 또는 포함 통일
- 구분선: 푸터 바 위에 얇은 라인 (`#4A6FA5`)

## 9. 전 발표 통합 변천 요약

| 차수 | 디자인 특징 | 변화 포인트 |
|---|---|---|
| 1차 | 다크 네이비 배경, 흰색 카드 테두리, 레드 불릿 | 기본 다크 테마 수립 |
| 2차 | (PDF 기준) 1차 스타일 유지 | — |
| 3차 | MD 기반 (PPT 사용), 코드블록 다이어그램 | 아스키 파이프라인 다이어그램 |
| 4차 | 왼쪽 세로 파랑 바 표지, 컬러 탑-바 카드, 타임라인 그래픽, 폰 목업 도입 | 디자인 대폭 개선 |
| 5차 | 4차 계승, 카드 모서리 더 둥글게, 색상 뱃지(NEW/LIVE), 표 스타일 세련화 | 완성도 향상 |
| **6차** | **5차 스타일 유지** | 내용만 업데이트 |
