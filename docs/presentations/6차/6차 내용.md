## 슬라이드 3 — 지난 발표 타임라인

**필수 기재 ① — 타임라인 그래픽 (점 + 선 형태, 5차 스타일):**

```
1차발표    2차발표    3차발표    4차발표    5차발표    6차발표 ★
 ●─────────●─────────●─────────●─────────●─────────★
1-2주차   3주차     5주차     8주차     10주차    13주차
아이디어   요구분석   백엔드    알파빌드   베타빌드   최종빌드
기획       완료       MVP완료   완료       완료       완성 ★
```

**필수 기재 ② — 주차별 핵심 달성 내용 (표):**

| 차수 | 핵심 달성 내용 |
|---|---|
| 1차 | 문제 정의 — 녹음·PDF·필기·AI 요약을 따로 쓰는 불편함 |
| 2차 | 기획 구체화 — 파이프라인 설계, 기술 스택 확정 |
| 3차 | 백엔드 완성 — FastAPI + Gemini AI (STT·LLM 통합) |
| 4차 | 알파 빌드 — 웹 UI 최초 공개, 실시간 스트리밍 생성 |
| 5차 | 베타 빌드 — 회원가입·로그인, 백그라운드 노트 생성, Render 배포 |
| **6차** | **최종 빌드 — 피드백 전원 반영, Android 패키징, Railway 배포** |

**필수 기재 ③ — 5차 → 6차 마일스톤 달성 항목 (5차에서 약속한 것):**
- ✓ 외부 피드백 5건 전원 반영 완료 — 다크모드 대비 보정 · 복수 파일 업로드 UI
- ✓ Android APK·AAB 패키징 완성 (PWABuilder TWA + Capacitor)
- ✓ Google Play 등록 신청 — 현재 심사 진행 중
- ✓ 배포 플랫폼 Railway 전환 (Render → Railway)

**슬라이드 하단:**
> 배포 URL: `https://lecturenote.up.railway.app`

## 슬라이드 6 — 향후 발전방향 ① B2B 확장

**필수 기재 내용 전체:**

### 핵심 메시지 (슬라이드 상단 강조)
> 이 파이프라인의 본질은 **강의 요약이 아닙니다.**  
> **비정형 멀티모달 입력 → 구조화 출력** AI 워크플로우입니다.

### Step 0 컨텍스트 교체만으로 도메인 전환

| Step 0 (컨텍스트) | 입력 | 출력 |
|---|---|---|
| 강의계획서 | 녹음 + 강의 PDF | 주차별 구조화 노트 |
| 안건 목록 | 회의 녹음 + 자료 | 결정사항·액션아이템 |
| 검토 체크리스트 | 계약서·보고서 PDF | 리스크·핵심 조항 요약 |
| 온보딩 가이드 | 교육 녹음 + 정책 문서 | 부서별 핵심 정리 |

**코드 변경 없음 — 컨텍스트 문서만 교체**

### 수익화 구조 (간략)
| 플랜 | 가격 | 대상 |
|---|---|---|
| Free | 무료 | 일반 학생 |
| Pro | ₩9,900/월 | 적극적 사용자 |
| Team | ₩29,900/월 | B2B 팀 단위 |

## 슬라이드 7 — 향후 발전방향 ② 기술 로드맵

**필수 기재 내용 전체:**

### 기술 로드맵

| 단계 | 조건 | 주요 변경 |
|---|---|---|
| **Phase 1 (현재)** | 검증 단계 | SQLite · 단일 FastAPI · Railway |
| **Phase 2** | 실사용자 발생 | PostgreSQL · bcrypt · S3 스토리지 |
| **Phase 3** | 동시 사용자 수십 명+ | 비동기 큐(Celery+Redis) · 전용 STT 서비스 |

**하단 주석:** 현재 스택은 몰라서가 아닌, 검증 전 복잡도 최소화를 위한 의도적 선택
