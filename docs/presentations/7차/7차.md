## 🟠 Major — 구조적 문제

### 3. 섹션 번호 중복 및 점프

현재 섹션 번호 흐름:

```
슬라이드 2,3 → 01. 지난 발표 돌아보기
슬라이드 4   → 02. 앱 실행 구조
슬라이드 5   → (헤더 없음)          ← 어느 챕터인지 불명확
슬라이드 6   → 05. 사용자 피드백    ← 02 다음에 갑자기 05!
슬라이드 7,8 → 02. 앱 시연         ← 02가 또 나옴 (중복)
슬라이드 9   → (헤더 없음)          ← 어느 챕터인지 불명확
슬라이드 10~13 → 03. 향후 발전방향
```

문제 요약:
- `02. 앱 실행 구조`(슬라이드 4)와 `02. 앱 시연`(슬라이드 7,8) → **02번 중복**
- `05. 사용자 피드백`이 `02` 다음에 등장 → **03, 04 건너뜀**
- 섹션 헤더 없는 슬라이드 2개 (슬라이드 5, 9)

제안 섹션 구조:
```
01. 지난 발표 돌아보기   (슬라이드 2, 3)
02. 앱 시연             (슬라이드 7, 8)  → 앞으로 이동 or 번호 통일
03. 사용자 피드백        (슬라이드 6)    → 번호 수정
04. 향후 발전방향        (슬라이드 10~13)
```
또는 현재 슬라이드 순서 유지하면서 번호만 정리:
```
01 → 지난 발표
02 → 앱 실행 구조 + 시연 (4,5,7,8을 하나의 02 챕터로 묶기)
03 → 사용자 피드백 (05→03으로 수정)
04 → 향후 발전방향 (03→04로 수정)
```

### 4. 타임라인이 6차 기준으로 종료

슬라이드 2 타임라인: 1차~6차로 끝나고 6차\*가 "최종빌드 완성\*"으로 표시됨.  
7차 발표라면 7차 항목 추가 또는 "5차→6차 달성 항목" 섹션을 "6차→7차"로 업데이트 필요.
