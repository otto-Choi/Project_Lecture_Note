# 렉쳐노트(LectureNote) 백엔드 상세 구현 가이드

본 문서는 사전에 정의된 프로젝트 디렉토리 구조를 바탕으로, FastAPI 기반의 로컬 파이프라인을 구축하기 위한 단계별 작업 명세서입니다.

---

## 전체 흐름 요약

```
[1회성 사전 작업]
POST /api/create-step0
강의계획서(PDF/텍스트) 업로드 → LLM 분석(syllabus_analysis.md 프롬프트) → Step 0 결과 → Lecture DB 저장

[매 주차 반복]
POST /api/generate-note
PDF + 음성 + 필기 업로드 → DB에서 Step 0 조회 → Data Aggregator → Gemini(make_note.md 프롬프트) → 노트 생성 → DB 저장
```

---

## 1단계: 데이터베이스 기초 공사 (`database.py`, `models.py`)

가장 먼저 데이터가 저장될 구조를 정의하고 연결을 설정해야 합니다.

**1. `database.py` (DB 연결 설정)**
* `sqlalchemy`를 사용하여 SQLite 데이터베이스 엔진을 생성합니다.
* 로컬 테스트용이므로 `sqlite:///./lecture.db` 경로를 사용합니다.
* 세션 팩토리(`sessionmaker`)와 베이스 모델 클래스(`declarative_base`)를 정의하여 다른 모듈에서 임포트할 수 있도록 합니다.

**2. `models.py` (테이블 스키마 정의)**
* 아래 3개의 테이블을 SQLAlchemy ORM 클래스로 구현합니다.
* `Lecture`: `id`(PK), `title`(강의명), `subject`(과목명), `step0_analysis`(Text, Step 0 분석 결과 저장), `created_at`
* `Source`: `id`(PK), `lecture_id`(FK → Lecture.id), `type`(STT/PDF/NOTE), `content`(텍스트), `created_at`
* `Output`: `id`(PK), `lecture_id`(FK → Lecture.id), `summary`(요약노트), `quiz`(예상문제), `created_at`

> **핵심:** `Lecture.step0_analysis` 컬럼에 Step 0 분석 결과가 저장되며, 이후 `/api/generate-note` 호출 시 이 컬럼을 조회하여 aggregator에 전달합니다.

---

## 2단계: 개별 입력 소스 처리 로직 구현 (`services/`)

외부 입력을 LLM이 처리할 수 있는 텍스트로 변환하는 모듈을 작성합니다.

**1. `services/pdf_parser.py`**
* `PyMuPDF`(`fitz`) 라이브러리를 활용합니다.
* 업로드된 PDF 파일의 바이트 스트림을 읽어 각 페이지의 텍스트를 추출하는 함수 `extract_text_from_pdf(file_bytes: bytes) -> str`를 작성합니다.
* 추출 시 페이지 번호 구분자를 추가하여 텍스트 구조를 유지합니다. (LLM 인식률 향상)

**2. `services/stt_service.py`**
* CLOVA Speech API 호출 로직을 구현합니다.
* `process_audio_to_text(audio_bytes: bytes) -> str` 함수를 작성합니다.
* **현재 단계:** 실제 API 호출 부분은 주석 처리하고, 하드코딩된 가짜 STT 텍스트를 반환하는 Mock 함수로 구현합니다. (API 크레딧 절약 및 개발 속도 향상)

---

## 3단계: 데이터 병합 및 프롬프트 준비 (`services/aggregator.py`)

개별적으로 추출된 텍스트들을 `make_note.md` 규칙에 맞게 하나의 컨텍스트로 조립합니다.

* `aggregate_sources(step0: str, pdf_text: str, stt_text: str, note_text: str) -> str` 함수를 작성합니다.
* 입력 자료를 명확하게 구분하는 태그를 삽입합니다.

```python
# 예시 포맷팅 로직
merged_text = f"""
[STEP 1: Step 0 강의 로드맵 분석 결과]
{step0 if step0 else '해당 없음'}

[STEP 2-1: PDF 변환 MD]
{pdf_text if pdf_text else '해당 없음'}

[STEP 2-2: 녹음 스크립트 TXT]
{stt_text if stt_text else '해당 없음'}

[STEP 2-3: 개인 필기]
{note_text if note_text else '해당 없음'}
"""
```

## 4단계: LLM 연동 및 결과 생성 (`services/llm_service.py`)

* `google.generativeai` 라이브러리를 설정하고 `.env`에서 `GEMINI_API_KEY`를 로드합니다.
* 아래 두 가지 함수를 작성합니다.

**1. `analyze_syllabus(syllabus_text: str) -> str`**
* `project_plan/syllabus_analysis.md` 파일을 런타임에 직접 읽어(`open()`) System Instruction으로 사용합니다.
* `syllabus_text`(강의계획서 내용)를 사용자 프롬프트로 전달하여 Step 0 분석 결과(마크다운)를 반환받습니다.

**2. `generate_lecture_note(aggregated_text: str) -> str`**
* `project_plan/make_note.md` 파일을 런타임에 직접 읽어(`open()`) System Instruction으로 사용합니다.
* `aggregated_text`(3단계 병합 결과)를 사용자 프롬프트로 전달하여 마크다운 형태의 요약 노트를 반환받습니다.

* 두 함수 모두 Gemini 1.5 모델(모델 ID: `gemini-1.5-pro-latest`)을 사용합니다.

---

## 5단계: 통합 파이프라인 구축 (`main.py`)

지금까지 만든 모든 부품을 조립하여 클라이언트가 호출할 수 있는 API를 엽니다.

* FastAPI 인스턴스를 생성하고, 앱 시작 시 `models.Base.metadata.create_all()`을 통해 DB 테이블을 자동 생성하도록 설정합니다.
* 아래 두 개의 POST 엔드포인트를 정의합니다.

---

### 엔드포인트 1: `POST /api/create-step0` (강의계획서 분석 및 Step 0 저장)

**수신 파라미터 (`Form` + `UploadFile`):**
* `title`: 강의명 (Form, str)
* `subject`: 과목명 (Form, str)
* `syllabus_file`: 강의계획서 파일 (UploadFile, PDF 또는 텍스트)

**내부 로직 순서:**
1. `title`, `subject`를 받아 `Lecture` 레코드를 먼저 생성하고 `lecture_id`를 확보합니다.
2. `syllabus_file`에서 텍스트를 추출합니다. (PDF이면 `pdf_parser.py` 활용, 텍스트이면 직접 decode)
3. `llm_service.analyze_syllabus()`를 호출하여 Step 0 분석 결과를 생성합니다.
4. 생성된 분석 결과를 해당 `Lecture.step0_analysis` 컬럼에 저장합니다.
5. `lecture_id`와 Step 0 분석 결과를 JSON으로 반환합니다.

---

### 엔드포인트 2: `POST /api/generate-note` (주차별 노트 생성)

**수신 파라미터 (`Form` + `UploadFile`):**
* `lecture_id`: 어떤 강의의 노트인지 식별 (Form, int)
* `pdf_file`: 수업 PDF (UploadFile, 선택)
* `audio_file`: 강의 녹음 파일 (UploadFile, 선택)
* `note_text`: 개인 필기 텍스트 (Form, str, 선택)

**내부 로직 순서:**
1. `lecture_id`로 DB에서 해당 `Lecture` 레코드를 조회하여 `step0_analysis`를 꺼냅니다. (없으면 404 에러 반환)
2. `pdf_parser.py`와 `stt_service.py`를 호출하여 텍스트를 추출합니다. (파일이 없으면 빈 문자열 처리)
3. `aggregator.py`를 호출하여 step0 + pdf + stt + note를 병합합니다.
4. `llm_service.generate_lecture_note()`를 호출하여 요약 노트를 생성합니다.
5. 원본 소스들을 `Source` 테이블에 저장합니다. (type별로 각각 저장)
6. 생성된 요약 노트를 `Output` 테이블에 저장합니다.
7. 생성된 마크다운 결과를 JSON으로 반환합니다.

---

## 6단계: 로컬 테스트 진행

* 터미널에서 `uvicorn main:app --reload` 명령어로 서버를 실행합니다.
* 웹 브라우저에서 `http://localhost:8000/docs` (Swagger UI)에 접속합니다.
* 테스트 순서:
  1. `/api/create-step0`에 강의계획서를 업로드하여 `lecture_id`와 Step 0 분석 결과를 확인합니다.
  2. 반환된 `lecture_id`를 사용하여 `/api/generate-note`에 PDF, 오디오, 필기를 업로드합니다.
  3. 최종 마크다운 요약 노트와 예상 문제가 정상 출력되는지 검증합니다.
