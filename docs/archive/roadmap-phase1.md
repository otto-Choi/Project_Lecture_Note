# Phase 1 완료 이력

> 학기 내 앱 완성 단계 (2026학년도 1학기) — 전부 완료

| 항목 | 내용 |
|---|---|
| STT 성능 최적화 | `thinking_budget=0` + `asyncio.gather` 병렬 PDF·STT |
| 스트리밍 자동 스크롤 | 생성 중 하단 자동 스크롤, 수동 스크롤 시 멈춤 |
| 사용자 인증 시스템 | 로그인·회원가입·세션 토큰·사용자별 데이터 격리 |
| 파이프라인 스텝 인디케이터 | Pipeline A — 연결선·서브텍스트·경과시간 카운터 |
| 프로필 화면 | Profile B — 통계·편집·비밀번호 변경·계정 삭제 |
| 백그라운드 노트 생성 | Gen-modal 팝업 → "백그라운드에서 진행" → 상단 배너, 배너 클릭 시 재표시 |
| 아이디/비밀번호 찾기 | 이름·학교로 아이디 찾기, 등록 이메일로 비밀번호 안내 |
| 구독 플랜 화면 | Free/Pro/Team 플랜 비교 카드 |
| 언어 설정 화면 | 한국어/English/日本語/中文 선택, DB 즉시 반영 |
| 가입 정보 화면 | 계정 상세 정보 조회 화면 |
| 비밀번호 강도 게이지 | 회원가입·비밀번호 변경 화면 공용 시각 지표 |
| 이용약관 동의 | 필수 2개 미동의 시 가입 버튼 비활성화 |
| 이메일 필드 | 회원가입 Step 1 — 비밀번호 찾기 연락처 |
| Railway 배포 | `render.yaml` → Railway 자동 배포 전환 |
| 다크모드 대비 개선 | 전체 배경 CSS 변수화(`var(--surface)`), 헤딩·텍스트 오버라이드, 캐시버스팅 |
| 노트 내 키워드 검색 | TreeWalker 하이라이트, 매치 수·↑↓ 탐색, Tab2·Tab3 공통 |
| Gen-modal 실시간 미리보기 | 모달 내 `#gm-preview` — LLM 생성 텍스트 실시간 출력 + 자동스크롤 |
| SVG 아이콘 안정화 | fetch 방식 → HTML 인라인으로 전환, 콜드스타트 아이콘 소실 해결 |
