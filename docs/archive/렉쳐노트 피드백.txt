중앙대 경영 20학번 이병헌.

1. UI 및 사용 편의성

앱 내 UI는 전반적으로 가독성이 좋고, 하단 탭을 통해 강의 등록, 노트 생성, 노트 조회로 이동하는 구조가 직관적이었다.
사용자에게 익숙한 모바일 앱 형태로 구성되어 있어 처음 사용하는 사람도 큰 어려움 없이 기능을 이해할 수 있을 것으로 보인다.

2. 학습 방식과의 적합성

대학 강의는 고등학교 수업과 달리 문제풀이 자료가 부족하고, 개념 중심의 암기 학습에 의존하는 경우가 많다.
하지만 모든 학생이 단순 암기 방식에 잘 맞는 것은 아니기 때문에, 강의 내용을 바탕으로 예상 문제를 자동 생성해주는 기능은 실제 학습에 도움이 될 수 있다고 판단된다.

3. 기존 AI 도구와의 차별성

현재도 GPT나 Gemini를 통해 문제를 만들 수는 있지만, 강의계획서, 수업자료, 녹음, 필기 내용을 함께 반영한 문제를 생성하기는 어렵다.
렉처노트는 수업 맥락을 기반으로 시험에 나올 가능성이 높은 포인트를 정리하고 문제화할 수 있다는 점에서 차별성이 있다.

4. 통합 플랫폼으로서의 장점

가장 긍정적인 부분은 녹음, 필기, PDF 요약, 예상 문제 생성이 하나의 플랫폼 안에서 가능하다는 점이다.
기존에는 녹음 앱, PDF 뷰어, AI 요약 도구, 필기 앱 등 최소 2개에서 많게는 3~4개의 플랫폼을 함께 사용해야 했지만, 렉처노트는 이 과정을 하나로 줄여준다.

5. 개선 필요점

다크모드 환경에서는 일부 화면의 시인성이 부족하게 느껴질 수 있어 색 대비 조정이 필요하다.
또한 현재는 수업자료나 녹음 파일을 여러 개 동시에 업로드하는 기능이 제한적인 것으로 보여, 여러 자료를 사용하는 수업에서는 사용자가 직접 파일을 합쳐야 하는 불편함이 발생할 수 있다.

앱 화면 구성이 복잡하지 않아서 처음 들어가도 어떤 순서로 사용해야 하는지 어느 정도 파악이 가능했다. 특히 하단에 강의 등록, 노트 생성, 노트 조회가 나뉘어 있어서 기능 이동이 직관적이었다.

가장 좋았던 점은 강의계획서와 수업자료, 녹음 내용을 따로 관리하지 않아도 된다는 점이다. 평소에는 녹음은 휴대폰 앱으로 하고, 자료는 LMS에서 따로 보고, 정리는 다시 AI에 복사해서 넣어야 했는데, 이 과정이 하나로 묶이면 확실히 편할 것 같다.

다만 처음 사용하는 입장에서는 ‘강의 등록’과 ‘노트 생성’의 차이가 바로 와닿지는 않았다. 강의 등록은 학기 초 1회만 하는 과정이고, 노트 생성은 매주 반복하는 과정이라는 안내가 조금 더 분명하면 좋을 것 같다.

대학 수업은 시험 대비 자료가 따로 제공되지 않는 경우가 많아서, 강의 내용을 바탕으로 예상 문제를 만들어주는 기능이 가장 유용해 보였다. 단순히 요약만 해주는 것이 아니라, 시험에 나올 수 있는 포인트를 정리해준다는 점에서 실제 공부에 도움이 될 것 같다.

특히 강의계획서를 먼저 분석하고, 그 흐름에 맞춰 주차별 노트를 만든다는 점이 좋았다. 그냥 AI에게 “이거 요약해줘”라고 하는 것보다, 수업 전체 맥락 안에서 정리된다는 점이 차별점이라고 느껴졌다.

아쉬운 점은 생성된 노트가 길어질 경우 모바일 화면에서 다소 빽빽하게 보일 수 있다는 점이다. 핵심 요약, 교수님 강조, 예상 문제 같은 부분이 더 확실히 나뉘어 보이면 읽기 편할 것 같다.

인하대 연극영화과 20 안경민

전체적인 UI는 모바일 앱처럼 구성되어 있어서 접근성이 좋았다. 렉처노트의 가장 큰 장점은 여러 학습 도구를 왔다 갔다 하지 않아도 된다는 점이다. 녹음, PDF 자료, 개인 필기, 요약, 문제 생성이 한 화면 흐름 안에서 이어지기 때문에 실제 수업 후 복습 시간을 줄이는 데 효과가 있을 것 같다.

다만 수업자료나 녹음 파일을 여러 개 올려야 하는 상황에서는 조금 불편할 수 있어 보였다. 대학 수업에서는 한 주차에 PDF가 여러 개 올라오거나, 녹음이 나뉘는 경우도 있기 때문에 복수 파일 업로드 기능이 추가되면 더 실사용에 가까워질 것 같다.

서울여대 국제학과 20 오수정

앱의 기능 자체는 실제 대학생들이 자주 겪는 불편함을 잘 건드린 것 같다. 수업을 듣고 나면 녹음은 남아 있지만 다시 듣기 부담스럽고, PDF는 따로 열어봐야 하고, 필기는 정리가 안 되는 경우가 많은데 이 부분을 하나로 묶은 점이 좋았다.

특히 예상 문제 생성 기능은 일반적인 AI 요약 서비스와 차이를 만드는 부분이라고 생각한다. 대학 수업은 문제집이 따로 있는 경우가 거의 없기 때문에, 강의 내용을 바탕으로 스스로 점검할 수 있는 문제가 만들어진다면 복습 방향을 잡는 데 도움이 될 것 같다.

개선할 점은 다크모드에서 일부 글자나 버튼 대비가 약하게 느껴질 수 있다는 점이다. 발표용 화면에서는 괜찮아 보이지만, 실제 사용자가 오래 보면 색 대비가 조금 더 강한 편이 좋을 것 같다.
